# Security Policy

## Supported Versions

Only the [latest release](https://github.com/0xGI0/PicConverter/releases/latest)
receives fixes.

## Reporting a Vulnerability

Please do **not** open a public issue for security reports. Use one of:

- **GitHub private vulnerability reporting** (preferred):
  [Report a vulnerability](https://github.com/0xGI0/PicConverter/security/advisories/new)
- **E-mail:** georgios@tertlidis.com — optionally PGP-encrypted
  (key: <https://tertlidis.com/pgp.asc>, fingerprint
  `D251 773E 1DF7 0C1D 0476 1CB0 F92A F40D 80E8 5351`)

You can expect an initial response within a few days.

## Release integrity

Every release ships SHA-256 checksums, Sigstore build-provenance attestations,
PGP signatures and a CycloneDX SBOM — see "Verify your download" in the README.
